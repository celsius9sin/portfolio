# portfolio

エンジニアとしての経験・スキルをまとめたポートフォリオサイト。

- `index.html` / `style.css` / `app.js`: 静的サイト本体(手動編集可、ビルド不要)。`data.json` を読み込んで描画する。
- `media/` と `app.js` の `WORKS`: 作品紹介(GIF・画像と説明)。data.json とは別に手で管理する。
- `data.json`: 掲載内容。**自動生成・上書きされるため手動編集しない。**

公開URL: https://d9sin.com/ (GitHub Pages の独自ドメイン。このリポジトリの main ブランチ、ルートから配信)。
